# argus-cli

> ⚠️ **Status: Future repository — not yet available.**
> This README describes planned functionality. The `argus-cli` repository is not yet released.

`argus-cli` is a unified command-line interface for querying 1M+ NCBI genome accessions across the seven ESKAPEE pathogens (*Enterococcus faecium*, *Staphylococcus aureus*, *Klebsiella pneumoniae*, *Acinetobacter baumannii*, *Pseudomonas aeruginosa*, *Enterobacter* spp., and *Escherichia coli*) through Argus-DB. Filter, export, and retrieve accessions for genomic surveillance.

Learn more at [www.argus-db.org](https://www.argus-db.org).
